# Paneles del README

`build.py` genera los SVG de `assets/readme/` (portada, botones, proyectos, trayectoria, stack, contribuciones y cierre) con la paleta azul petróleo y cian del perfil.

```bash
pip install fonttools brotli
python tools/readme/build.py
```

Para cambiar un dato (un proyecto, una cifra, una certificación), edítalo en `build.py` y vuelve a ejecutarlo. Fuentes: Space Grotesk y JetBrains Mono (OFL). Íconos: Simple Icons (CC0).
